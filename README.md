Open `index.html` in a browser. Press **S** for the speaker view (notes) and **F** for full screen.

## Render from source

Requires [Quarto](https://quarto.org) (1.4 or later):

```bash
quarto render cf_multistate.qmd
```

Formulas use MathML, so the rendered HTML works offline.
